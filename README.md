How to use on Windows:
1.  Save as spammer.py
2.  Double-click or open Command Prompt / PowerShell / Windows Terminal
3.  Run: python spammer.py
Remember: Fill in your own Gmail emails and App Passwords in the accounts section.

How to Run on MacBook:
1.  Open TextEdit
2.  Paste all the code above
3.  Click File → Save
4.  Name it: spammer.py
5.  Important: At the bottom right, change Format to Plain Text
6.  Save it to your Desktop
7.  Open Terminal and run these commands:
8.  cd ~/Desktop
python3 spammer.py
